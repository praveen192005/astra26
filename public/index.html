How to Host on Render (Free & Fast):

  1. Create a free account on render.com.
  2. Push this project to a GitHub repository.
  3. Click New + → Web Service → Select your GitHub repository.
  4. Render detects render.yaml or select Python 3 with start command: uvicorn main:app --host 0.0.0.0 --port $PORT.
  5. Copy your public Render URL (e.g., https://astra26-hub.onrender.com) into SERVER_URL inside your ESP32 Arduino code!
